# 华普智选 — 全站交互规范

> 版本：v1.0 · 状态：定稿  
> 配套：`docs/DESIGN.md`（视觉）· `docs/COMPONENT-SPEC.md`（组件）· `docs/FLOWS.md`（流程）· `docs/PRD.md`（验收）

本文件是登录、运营看板、商品管理、市场趋势、选品推荐、竞品监控、Listing 优化、库存预警八页的统一交互基线。页面局部规则不得覆盖本文件的状态、反馈、鉴权与可访问性约束。

---

## 1. 总体原则

1. **保留上下文**：筛选、翻页、局部刷新时保留 AppShell、表头和已有数据。
2. **动作可追踪**：写操作必须有进行中、成功或失败反馈；失败不清空输入、不伪造成功态。
3. **防重复提交**：请求期间禁用同一触发器；连续查询取消旧请求或忽略旧响应。
4. **结构稳定**：Loading / Empty / Error 与成功态使用相同容器，避免布局跳动。
5. **短动效**：Hover 120ms；横条 160–200ms；抽屉、弹窗 240ms。
6. **不只靠颜色**：状态同时使用文字、图标、箭头、色条或删除线。
7. **URL 可恢复**：列表 Tab、筛选、排序、分页和当前对象优先写入 query。

## 2. 全站三态

### 2.1 Loading

#### 首次加载

- AppShell 先稳定渲染；内容按最终结构显示骨架，不使用占满整页的大 Spinner。
- 卡片保持最终尺寸；表格保留表头并显示 5–8 行骨架；图表保留标题、图例和绘图区。
- 骨架 `#E5E7EB`，shine `#F3F4F6`，shimmer `1.2s linear loop`。
- 超过 8 秒显示「加载时间较长，可重试」，不得永久无文案等待。

#### 局部刷新

- 筛选、排序、翻页时保留旧数据，在数据区叠加低透明度遮罩和小 Spinner。
- 成功后一次性替换；失败时保留旧数据，移除遮罩并显示区块级「重试」。
- 后返回的旧请求不得覆盖最新筛选条件。

#### 按钮与 AI 生成

- 按钮 Loading 保持原宽，显示 14px Spinner +「同步中… / 保存中… / 生成中…」，并禁用等价入口。
- AI 生成使用结构匹配的正文骨架，不逐字输出；成功后整块内容 180ms 淡入。
- AI 失败不保留残稿、不覆盖原文；显示原因摘要与「重新生成」。
- `prefers-reduced-motion: reduce` 下取消 shimmer 和位移。

### 2.2 Empty

- 空状态位于所属容器内，不移除页面标题、筛选和 AppShell。
- 结构：单色线性图标 → 16px/600 标题 → 12px 说明 → 可选一个 Primary。
- 初始无数据说明如何创建或同步；筛选无结果显示「清空筛选」，不引导重复创建。
- 表格空状态跨全部列；图表保留标题与时间范围；禁止破折号墙和装饰插画。

### 2.3 Error

| 范围 | 表现 | 行为 |
|------|------|------|
| 字段校验 | Danger 边框 + 字段下 12px 错误 | 修正后清除 |
| 区块失败 | 原位 Danger Alert +「重试」 | 其他区块仍可用 |
| 列表刷新失败 | 表格上方 Alert | 保留旧数据和条件 |
| 页面核心失败 | 内容区错误状态 | 保留 AppShell |
| 写操作失败 | `ElMessage.error` | 不改变本地成功态 |
| AI 失败 | 原位错误块 | 不展示残稿 |

- 文案必须包含对象和下一步，例如「同步商品失败，请检查网络后重试」。
- 同一错误只反馈一次；已有区块 Alert 时不叠加同文案 Message。
- 401 按 §8 处理；403 留在当前页并提示无权限。

## 3. 反馈

### 3.1 ElMessage

ElMessage 用于已经完成或立即失败、无需持续阅读上下文的轻量反馈。

| 类型 | 场景 | 示例 | 时长 |
|------|------|------|------|
| success | 保存、复制、同步触发、标记已读、采纳成功 | 已标记为已读 | 3s |
| info | 恢复默认、非关键提示 | 已恢复默认筛选 | 3s |
| warning | 非阻断限制、数据可能过期 | 数据更新时间超过 24 小时 | 4s |
| error | 写操作或短请求失败 | 采纳失败，请重试 | 5s，可关闭 |

- 距顶栏 16px；同类消息 2 秒内合并，最多同时 3 条。
- 普通跳转、Tab 切换、筛选不弹 Message。
- 字段校验、持续告警和确认操作不得用 Message 代替。
- 401 只在登录页显示一次过期提示，不对每个失败请求弹错。

### 3.2 确认弹窗

必须确认：

- 删除、批量移除、清空记录。
- 拒绝选品、回滚 Listing、替换当前生效版本。
- 批量标记已读、修改全局阈值。
- 离开存在未保存编辑的页面。

无需确认：单条标记已读、复制、导出、普通筛选和只读跳转。

规则：

- 标题使用明确动作，如「移除这个竞品？」；正文说明对象与影响。
- 默认焦点在「取消」；破坏性确认使用 Danger，Enter 不得误触。
- 提交期间确认按钮 Loading；失败保留弹窗与输入。
- 关闭后焦点回到触发元素。

## 4. 抽屉、弹窗与横条动效

### 4.1 Drawer

- 右侧进入，默认宽 480px，复杂详情 640px；移动端 `100vw`。
- 进入 240ms `ease-out`：`translateX(100%) → 0`；退出 200ms `ease-in`。
- 遮罩 `rgba(17,24,39,.45)` 在 160ms 内淡入/淡出。
- 打开后锁定背景滚动，焦点进入抽屉并限制在内部；关闭后回到触发元素。
- 只读抽屉支持 Esc、关闭按钮和遮罩关闭；有未保存内容时先确认。

### 4.2 Dialog

- 遮罩 160ms 淡入；弹窗 240ms `ease-out` 从 `opacity:0; translateY(8px)` 到终态。
- 普通宽 420–560px；复杂表单改用抽屉或独立页。
- 打开后锁定背景，只让最上层弹窗响应 Esc；关闭后恢复焦点。
- 避免抽屉上再叠详情弹窗；确认弹窗是允许的轻量二层。

### 4.3 Alert Banner

- 在内容顶部原位插入，160–200ms `ease-out`：淡入并从上方移动 4px。
- 关闭时 160ms 淡出并收起高度；关闭只隐藏，不等同已读。
- High 使用 `role="alert"`；Medium / Low 使用 `role="status"`。
- 多条同时出现只展开最高 severity 的最新一条，其余收为「另有 N 条」。
- 横条可驻留，不自动消失；短成功反馈仍使用 ElMessage。

### 4.4 Reduced Motion

- 减少动态模式取消位移、shimmer、数字滚动和图表重播。
- 使用 ≤100ms 透明度切换或直接显示终态。

## 5. 表格

### 5.1 Hover、焦点与选中

- 默认行高 40–44px；含缩略图时 48–56px。
- 普通 Hover 使用 `#F9FAFB`，120ms ease。
- 整行可点击时使用指针；行内按钮阻止行点击，避免误开详情。
- 键盘焦点使用可见 Primary 外环，不移除默认焦点而无替代。
- 普通选中行：`#EEF2FF` + 左侧 3px Primary。

### 5.2 语义行

- 告警：`#FEF2F2` + 左 3px Danger +「告警」标签。
- 预警：`#FFFBEB` + 左 3px Warning +「预警」标签。
- 正常：白底 +「正常」Success 标签。
- 语义行 Hover 只轻微加深原色，不改成灰色。
- 选中语义行时保留状态色条/标签，另加 Indigo 轮廓或勾选表示操作对象。

### 5.3 排序、筛选与分页

- 当前排序方向必须可见；筛选、排序、页码同步 URL。
- 改变筛选、排序或每页数量后回到第 1 页；仅翻页时保留条件。
- 默认 20 条/页，可选 20/50；显示总数、当前页和总页数。
- 请求期间禁用重复翻页；失败保持原页。删除导致当前页为空时回退上一页。

## 6. 375px 移动端

### 6.1 AppShell

- 侧栏改为全高导航抽屉，默认关闭；顶栏显示菜单按钮。
- 内容左右内边距 16px；页面 Body 禁止横向滚动。
- KPI 单列、图表减省刻度、抽屉全屏、告警横条操作区换行。
- Listing 在 ≤768px 由双栏改为上下堆叠，原版在上、AI 版在下。

### 6.2 表格横向滚动

- 仅表格容器使用 `overflow-x:auto` 与原生惯性滚动，Body 不横向撑破。
- 普通表最小宽 720–840px，高字段表 960px；不得强压所有列。
- 第一关键列可 `sticky left`，宽 160–200px，并用轻阴影提示仍可滚动。
- 操作列不与首列同时固定形成夹层；移动端优先放末端或收入「更多」。
- 分页放在滚动容器外；移动端保留上一页、当前页/总页、下一页。
- 首次进入可显示一次「左右滑动查看更多」；滚动后隐藏。
- 触摸目标 ≥32px，主要操作 ≥36px；不得劫持页面纵向滚动。

## 7. 路由与跨页同步

- Tab、筛选、排序、分页写入 query；详情抽屉可用 `id` query，关闭时移除。
- P3 → P4 携带品类；P5 → P7 携带关联商品/告警；P1 KPI 跳到对应筛选态。
- 选品接受/拒绝同步 P4 与 P1；告警已读同步 P7、P1 与侧栏角标。
- Listing 采纳/回滚同步当前版本与时间线；竞品降价同步 P5、P7 和 P1。
- 刷新后以后端持久状态为准，不从本地 Message 推断成功。

## 8. 401 跳登录

### 8.1 统一流程

1. 任一 API 返回 401 或凭证预检失效时，进入全局 single-flight；并发 401 只处理一次。
2. 停止新的鉴权请求，取消可取消的在途请求。
3. 清除 Token / Session、用户信息和权限缓存；保留纯展示偏好。
4. 保存安全站内 `returnUrl`（pathname + search + hash），拒绝外域 URL。
5. 使用 replace 跳转 `/login?reason=expired&returnUrl=...`，防止返回失效页循环。
6. 登录页只显示一次「登录状态已过期，请重新登录」。
7. 登录成功后回合法 returnUrl；没有时进入首页 `/`。

### 8.2 边界

- 登录接口返回 401：停留登录页，字段级提示账号或密码错误，不循环跳转。
- 403：不清 Session、不跳登录，原位提示无权限。
- 主动退出：清 Session 后 replace `/login`，不保存 returnUrl。
- 未保存草稿可写 sessionStorage；敏感字段不得写入 URL。

## 9. 页面关键交互

- **登录**：提交按钮 Loading；成功 replace 到 returnUrl 或 `/`。
- **看板**：KPI、榜单、图表跳到对应预筛选页；时间变化只刷新数据区。
- **商品**：父节点箭头只展开，名称才切换；同步按钮 Loading；价格历史用 Dialog。
- **趋势**：同一时间只展开一行；旧详情 120ms 收起，新详情 180ms 展开；旧请求不得覆盖新选中品类。
- **选品**：AI 分析用 Drawer；接受确认对象；拒绝可填原因；成功同步 Tab 数量和看板。
- **竞品**：切换商品同步表格与折线；移除需确认；横条关闭不等于已读。
- **Listing**：生成中保留左侧原文；采纳需确认；失败不覆盖原版。
- **库存**：默认突出告警/预警；标记处理后同步统计条、行状态和侧栏角标；阈值仅主管可编辑。

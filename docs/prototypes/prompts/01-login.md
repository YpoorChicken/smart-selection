# 原型提示词 · 01-login

**Design Read：** 像 Shopify Admin 一样熟悉的工作台骨架，像 Jungle Scout 一样密集的数据面——Indigo 主色、表格与图表优先，专为跨境运营团队长时间盯盘与快速决策而设计。

**引用 DESIGN.md：**  
Primary `#4F46E5` · Primary-hover `#4338CA` · On-primary `#FFFFFF` · Canvas `#F3F4F6` · Surface `#FFFFFF` · Ink `#111827` · Ink-secondary `#374151` · Ink-muted `#6B7280` · Hairline `#E5E7EB` · Hairline-strong `#D1D5DB` · Danger `#DC2626`（错误态可用）· Spacing：页面级留白可用 64px，卡片内边距 24px，控件间距 12–16px · Radius md 6px / lg 8px · 阴影 `elevation.modal` 或 `raised` 轻冷灰 · 系统字体栈（Segoe UI / PingFang SC / Microsoft YaHei），禁止 Inter。  
本页为 A0：**无侧栏、无顶栏、无面包屑**。

## 画面构图（桌面 1440px 宽）

生成一张 **1440×900** 的高保真登录/注册页桌面截图（中文 UI），居中认证卡片，品牌清晰。

**布局：**

1. **全屏背景**：浅灰画布 `#F3F4F6`（可有极弱的冷灰几何或细网格氛围，**禁止**紫粉渐变、禁止大插画英雄图）。非工作台壳层。

2. **垂直水平居中的白色认证卡片**（宽约 400–440px）
   - 白底 `#FFFFFF`、圆角 12px（`xl`）、细边框 `#E5E7EB`、轻阴影
   - 内边距约 32–40px

3. **品牌区（卡片顶部）**
   - 产品名「华普智选」作为品牌级信号（约 20–22px，字重 600，`#111827`）
   - 一句短支持文案（caption / muted）：如「智能选品与跨境运营中台」
   - 品牌在卡片内视觉权重高于表单标签；不要用巨大营销 slogan 压过品牌名

4. **Tab 切换（主操作区顶部）**
   - 「登录」|「注册」两个 Tab
   - **当前为登录 Tab 选中**：选中文字 `#4F46E5` 或 ink，底部 2px 主色指示线；未选中 `#6B7280`
   - 清晰表达可切换到注册（注册 Tab 可见但未选中）

5. **登录表单**
   - 账号（邮箱/手机）输入框：高 32–36px，边框 `#D1D5DB`，圆角 6px
   - 密码输入框：同上，右可有显示/隐藏图标占位
   - 主按钮「登录」：实心 `#4F46E5`、白字、圆角 6px、全宽或接近全宽，高 36px
   - 次操作：弱链接「忘记密码？」（muted，占位即可）
   - 底部一句：「还没有账号？切换到注册」类辅助文案（指向 Tab）

整体气质：专业冷静的 B2B 鉴权入口，克制、可信，不是消费级炫彩登录页。

## 必须出现的 UI 元素清单

- [ ] 浅灰全屏底 + **居中白卡片**（无 AppShell 侧栏/顶栏）
- [ ] 品牌区：「华普智选」+ 一句产品说明
- [ ] **登录 / 注册 Tab**，登录为当前选中态
- [ ] 账号输入框、密码输入框
- [ ] 主色实心「登录」按钮 `#4F46E5`
- [ ] 次要链接「忘记密码」或注册引导文案至少其一
- [ ] 中文界面文案
- [ ] 8px 网格感的整齐间距与 6px 圆角控件

---

## 禁止项

- AI 紫粉 / 紫到靛蓝大面积渐变背景、左右分屏大图营销墙
- 玻璃拟态、霓虹光晕、厚重彩色投影
- Inter / 展示衬线 / 手写体作为主字体
- 三列特性卖点、插画英雄、表情包、社交登录大图标墙（除非极弱占位且非焦点）
- 大圆胶囊按钮、圆角过度的「超级 App」皮肤
- 出现深色侧栏或后台顶栏（本页无壳）
- 主按钮非 Indigo 或整卡刷成紫色
- 英文 Lorem 乱码喧宾夺主

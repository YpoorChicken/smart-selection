# 原型提示词 · 04-selections 选品推荐

**Design Read：** 像 Shopify Admin 一样熟悉的工作台骨架，像 Jungle Scout 一样密集的数据面——Indigo 主色、表格与图表优先，专为跨境运营团队长时间盯盘与快速决策而设计。

## 共用画面构图（桌面 1440×900）

生成中文高保真 B2B SaaS 后台截图，展示「华普智选」P4 选品推荐页。严格复用 AppShell：左侧 220px 深色侧栏、顶部 56px 白色顶栏、主画布 `#F3F4F6`、24px 页面边距；「选品推荐」为当前选中态。

- 顶栏标题「选品推荐」，右侧角色「选品经理」、用户「张敏」。
- 页面顶部为三个 Tab：「蓝海发现」（当前选中）/「推荐列表」/「已接受」，选中态为 Indigo 文字与 2px 下划线，并显示数量。
- Tab 下方为紧凑筛选条：Amazon、美国站、全部品类、综合分从高到低、搜索；右侧显示「本周新增 12」。
- 主区参考 Jungle Scout 的高密度选品卡片，采用 3 列网格；白底、1px 细边、8px 圆角、轻阴影。
- 每张卡：顶部商品名、品类与 Amazon 小 Tag；左侧约 88px 蓝海指数圆环，右侧四维进度条；底部价格带、预估毛利、风险标签与操作。
- 圆环显示大数字与「蓝海指数」：86/绿色、74/琥珀、58/红色；轨道浅灰、圆弧 8px，不做速度表或渐变光效。
- 四维固定为「市场需求、竞争强度、利润空间、趋势方向」，显示 0–100 数字与同色阶细进度条。
- 风险标签如「季节性中」「专利风险低」「供应链波动」，使用偏方 4px 标签；不得用大胶囊。
- 卡片操作为「查看 AI 分析」弱按钮、「接受」唯一实心 Indigo 主操作、「拒绝」次按钮。

### 图 A：默认态 `04-selections-default.png`

- 无遮罩、无抽屉，完整展示两行卡片网格，首行至少 3 张。
- 第一张「开放式无线耳机」蓝海指数 86，四维 92/78/84/88；第二张「便携榨汁杯」74；第三张「宠物智能饮水机」58。
- 卡片信息紧凑但不拥挤，用户能快速比较分数、风险和决策动作。

### 图 B：关键交互态 `04-selections-drawer.png`

- 点击第一张「查看 AI 分析」后，从右侧打开约 520px 半屏抽屉；页面其余区域覆盖冷黑半透明遮罩，底层卡片仍可辨识。
- 抽屉顶栏：标题「AI 选品分析」、商品名、蓝海指数 86、关闭图标；正文按 Markdown 阅读层级分为四块：
  1. `## 市场机会`：需求增长、价格带、样本依据；
  2. `## 竞争格局`：头部集中度、评论门槛、差异化空间；
  3. `## 利润与风险`：预估毛利 31.8%、季节性/专利/供应链风险；
  4. `## 行动建议`：首批备货、目标售价、验证周期的编号清单。
- 四块使用标题、正文、项目符号、少量加粗，不做聊天气泡；区块以细分割线分隔。
- 抽屉底部固定操作栏：「拒绝」Secondary 与「接受该选品」Primary；全屏只出现一个实心主按钮。
- 点击「接受该选品」确认后记录状态、操作人、操作时间并进入「已接受」Tab；点击「拒绝」确认后同样记录「已拒绝」、操作人和时间，并从默认待处理列表移除。刷新后记录保持。

### 图 C：已接受记录态 `04-selections-accepted.png`

- 切换到「已接受」Tab，展示已完成决策的推荐列表；每行或卡片必须显示综合分与四维分项摘要。
- 状态列使用绿色标签「已接受」，并明确显示「操作人：张敏」「操作时间：今天 15:26」；另一条示例可显示「李然 · 昨天 18:40」。
- 顶部保留 Tab 数量，已接受为 `28`；提供弱操作「查看分析」，不再显示接受/拒绝按钮。
- 页面右上或列表辅助区说明「决策记录已同步至运营看板」，用于表达状态持久化与跨页汇总。

## 必须出现

- [ ] 蓝海发现 / 推荐列表 / 已接受三个 Tab
- [ ] 3 列高密度选品卡片网格
- [ ] 蓝海指数大圆环 + 四维进度条 + 风险标签
- [ ] 综合分严格按 ≥80 绿、60–79 琥珀、<60 红
- [ ] 默认态无抽屉；交互态有右侧半屏抽屉、遮罩、Markdown 四块与固定操作栏
- [ ] 已接受记录态明确显示状态、操作人和操作时间
- [ ] 中文 UI；深色侧栏、浅灰画布、白卡片

## 禁止项

- 页面级紫粉渐变、玻璃拟态、霓虹、3D 仪表盘、彩虹圆环
- 营销 Hero、插画、低密度大卡、圆角过度、胶囊按钮成排
- 把蓝海指数做成无阈值含义的蓝紫渐变；风险标签颜色滥用
- 抽屉做成聊天窗口，或出现多于一个实心主按钮
- Inter、展示字体、英文 Lorem、乱码

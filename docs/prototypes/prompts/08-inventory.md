## 画面构图（桌面 1440×900）

生成一张中文高保真 B2B SaaS 后台截图，展示「华普智选」库存预警页，路由 `/inventory-alerts`。严格复用已有 AppShell：左侧 240px 深色侧栏、顶部 56px 白色顶栏、主画布 `#F3F4F6`、24px 页面边距；「库存预警」当前选中并带红色未读角标 `2`。

### 1. 顶栏与统计条

- 顶栏标题「库存预警」，右侧角色「运营」、用户「李然」。
- 内容顶部是一张横向白色统计条，分成三个等宽指标，中间用竖直 `#E5E7EB` 分割线，不做三张营销卡：
  1. 「库存商品总数」`128`，中性 Ink 大数字；
  2. 「库存告警」`2`，红色大数字，辅助「预计 3 天内售罄」；
  3. 「库存预警」`5`，琥珀大数字，辅助「低于 14 天安全库存」。
- 每项含 28px/600 数字、12px 标签、简洁线性图标；统计条白底、1px 细边、8px 圆角、轻冷灰阴影。

### 2. 筛选与阈值说明

- 统计条下方为白色紧凑工具条：搜索「商品名 / SKU」、状态「全部状态」、品类「全部品类」、仓库「美国西部仓」、排序「可售天数升序」。
- 右侧显示阈值说明「告警 ≤3 天 · 预警 ≤14 天」，旁边 Secondary「阈值设置」；仅运营主管可编辑的含义可用小锁图标弱提示。
- 辅助信息显示「最近更新：今天 16:42」。

### 3. 库存风险表格

- 主体为白色高密度表格卡，标题「库存风险明细」，右上显示「共 128 条」。
- 表头 `#F9FAFB`，列必须包含：商品、SKU、可用库存、近 7 日日均销量、预计可售天数、安全库存、库存状态、更新时间、操作。
- 商品列含 40×40 简洁缩略图、中文商品名、Amazon 小 Tag；SKU 使用 12px 等宽字。
- 数字列右对齐；预计可售天数为视觉重点。
- 行背景按库存状态严格区分：
  - **告警**：整行浅红 `#FEF2F2`，左侧 3px `#DC2626`，状态标签红底红字「告警」；
  - **预警**：整行浅橙 `#FFFBEB`，左侧 3px `#D97706`，状态标签橙底橙字「预警」；
  - **正常**：白底，状态标签绿底绿字「正常」。
- 示例数据：
  - 折叠旅行收纳包，库存 `6`，日均 `2.4`，可售 `2.5 天`，安全库存 `34`，告警；
  - USB-C 多口充电器，库存 `11`，日均 `3.1`，可售 `3.5 天`，安全库存 `44`，告警；
  - 开放式无线耳机，库存 `38`，日均 `4.2`，可售 `9.0 天`，安全库存 `59`，预警；
  - 宠物智能饮水机，库存 `52`，日均 `4.6`，可售 `11.3 天`，安全库存 `65`，预警；
  - 硅胶厨具套装，库存 `126`，日均 `3.8`，可售 `33.2 天`，安全库存 `54`，正常。
- 行内操作为「查看商品」「标记已处理」；正常行只显示「查看商品」。不提供采购、补货下单或物流动作。
- 表格底部显示分页：「共 128 条」「20 条/页」「1 / 7」。

### 4. 告警记录补充态 `08-inventory-alerts.png`

本页同时承接 PRD P6 告警中心 Must；在统计条下提供 Tab「库存风险 / 告警记录」，补充态切换到「告警记录」。

- 顶部未读摘要与侧栏角标均显示 `3`，并有筛选：未读 / 告警类型 / 时间范围。
- 告警表格列必须包含：已读状态、告警类型、关联商品 / 竞品、触发阈值、触发值、触发时间、操作。
- 示例至少包含：
  - 未读「竞品降价」，SoundPeak Air 3 / 开放式无线耳机，阈值 `5%`，触发值 `-8.6%`，`18 分钟前`；
  - 未读「库存不足」，折叠旅行收纳包，阈值 `≤3 天`，触发值 `2.5 天`，`今天 15:48`；
  - 已读「评分下降」，NovaPods Open，阈值 `-0.3`，触发值 `-0.4`，`昨天 20:12`。
- 未读行使用语义浅底和左侧色条，已读行白底弱化；单条操作「标记已读」与「查看关联对象」。
- 点击「标记已读」后，当前行转为已读，顶部未读数与侧栏角标同步减 1；静态图用一条已读示例与一条未读示例表达差异。

## 必须出现

- [ ] 顶部统计条：总数 128 / 告警 2 / 预警 5
- [ ] 告警浅红行、预警浅橙行、正常白行，色彩范围克制
- [ ] 状态标签语义色：告警红 / 预警橙 / 正常绿
- [ ] 可用库存、日均销量、预计可售天数、安全库存等决策字段
- [ ] 搜索筛选、阈值说明、更新时间、分页
- [ ] 告警记录补充态覆盖类型、关联对象、阈值、触发时间、已读/未读与单条标记已读
- [ ] 深色侧栏中「库存预警」选中并有未读角标；中文 UI

## 禁止项

- 把整张表染成高饱和红橙；状态只靠背景色而没有文字标签
- 采购下单、物流跟踪、供应商管理等超出项目范围的操作
- 页面级紫粉渐变、玻璃拟态、霓虹、厚重阴影、营销 Hero
- 大圆角、胶囊按钮成排、装饰插画、3D 图表
- Inter、展示字体、英文 Lorem 或乱码

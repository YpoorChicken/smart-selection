# 原型提示词 · 02-products 商品管理

## 画面构图（桌面 1440×900）

生成一张中文高保真 B2B SaaS 后台截图，展示「华普智选」P2 商品管理页。严格复用已定稿 AppShell：左侧 220px 深色侧栏、顶部 56px 白色顶栏、主画布 `#F3F4F6`、24px 页面边距。

### 1. AppShell

- 侧栏包含完整导航分组；「商品管理」为当前选中态：`#312E81` 背景、白字、左侧 3px Indigo 指示条。
- 顶栏左侧显示面包屑「运营执行 / 商品管理」与页面标题「商品管理」；右侧为角色「运营」和用户「李然」。
- 主色只用于主操作、焦点和关键价格，不做大面积背景。

### 2. 顶部搜索筛选条

- 白色卡片，高密度横排：搜索框「搜索标题 / ASIN」、平台筛选「全部平台」、品类筛选「全部品类」、排序「评分从高到低」、勾选「仅看自营关注」。
- 右侧次按钮「导出」，主按钮显示 **loading 态**：「同步中…」；按钮内 14px 小型旋转指示，禁用重复点击，按钮保持 Indigo，不出现整页大 Spinner。
- 下方辅助文字显示「最近同步：今天 16:42」。

### 3. 主内容：左品类树 + 右商品表格

- 左侧约 220px 白卡片「品类」，树形层级带展开箭头与数量；当前选中「无线耳机 128」使用 `#EEF2FF` 浅底和 Indigo 字色。示例层级包含「电子产品 / 耳机 / 无线耳机」「家居厨房」「宠物用品」。
- 右侧为高密度商品表格，表头 `#F9FAFB`，行高 52–56px，细分割线。
- 列必须包含：复选框、商品图（40×40 简洁占位缩略图）、标题与 ASIN、平台标签、**所属品类**、价格、评分、销量排名、最近同步、操作。
- 商品标题 14px/600，超长单行省略；ASIN 使用 12px 等宽弱文字。
- 价格右对齐，Indigo `#4F46E5`、加粗；评分按语义色：≥4.5 绿色、4.0–4.4 琥珀、<4.0 红色。
- Amazon / Shopee 只用小型偏方 Tag，不做大色块。
- 右侧操作显示「详情」「价格历史」；底部分页显示「共 128 条」「1 / 7」。

### 4. 必须标注的三种交互状态

在不破坏主表阅读的前提下，用细线引导与小标题明确标注：

1. **同步按钮 · loading**：顶部主按钮显示小 Spinner +「同步中…」，旁注「保留表头，表区可局部遮罩」。
2. **空状态**：左下或表格下方放一张小型状态样例卡，内容为单色线性盒子图标、标题「还没有同步商品」、说明「去配置采集任务后再同步」、主按钮「配置采集」；禁止插画。
3. **价格历史弹窗**：画面右下覆盖一个宽约 420px 的白色模态样例，带轻遮罩/阴影、标题「价格历史」、商品名、近 30 天 Indigo 折线、最高/最低/当前价、关闭按钮；弹窗圆角 8px，动画含义为 240ms ease-out。

### 5. 数据采集配置补充态 `02-products-collection.png`

用于承接 PRD P8 的 Must 能力，不新增侧栏一级页面；从本页「配置采集」打开右侧 560px 抽屉。

- 抽屉标题「数据采集配置」，表单包含：平台（Amazon）、关注品类（可多选）、采集频率（每小时 / 每日）、触发方式（定时 / 手动）、启用开关；底部唯一主按钮「保存配置」。
- 抽屉下半部展示「最近采集任务」表格：任务 ID、平台、品类、触发方式、开始时间、状态、完成率；必须同时出现成功、进行中、失败三种状态。
- 成功使用绿色标签与 `100%`；进行中使用 Indigo 进度条如 `68%`；失败使用红色标签、完成率 `32%` 和弱操作「查看错误」。
- 底层商品表仍可辨识，且必须显示「所属品类」列；抽屉使用冷黑半透明遮罩。

## 必须出现

- [ ] 左品类树 + 右商品表格 + 顶部搜索筛选
- [ ] 商品图、标题、平台标签、所属品类、Indigo 加粗价格、语义色评分
- [ ] 同步按钮 loading 态、空状态、价格历史弹窗均有清晰标注
- [ ] 补充态覆盖采集配置（平台/品类/频率或触发方式）和最近任务成功/进行中/失败与完成率
- [ ] 220px 深色侧栏，商品管理选中；56px 顶栏
- [ ] 表格分页、最近同步时间、行内操作
- [ ] 中文 UI，数据密度高但对齐清楚

## 禁止项

- 紫粉渐变背景、玻璃拟态、霓虹或厚重彩色阴影
- 大圆角卡片、胶囊按钮成排、营销 Hero、装饰插画
- 用平台色做主 CTA；用大 Spinner 遮住整页
- 超大标题、低密度卡片墙、3D 图表、彩虹配色
- Inter 或展示字体；英文 Lorem / 乱码

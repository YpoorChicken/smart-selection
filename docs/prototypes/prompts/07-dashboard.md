# 原型提示词 · 07-dashboard 运营看板首页

**Design Read：** 像 Shopify Admin 一样熟悉的工作台骨架，像 Jungle Scout 一样密集的数据面——Indigo 主色、表格与图表优先，专为跨境运营团队长时间盯盘与快速决策而设计。

**引用 DESIGN.md：**  
Primary `#4F46E5` · Primary-subtle `#EEF2FF` · Chart-2 `#0EA5E9` · Success `#059669` · Warning `#D97706` · Danger `#DC2626` · Canvas `#F3F4F6` · Surface `#FFFFFF` · Surface-sunken `#F9FAFB` · Ink `#111827` · Ink-muted `#6B7280` · Hairline `#E5E7EB` · Sidebar `#111827` · Sidebar-active `#312E81`。系统字体栈；页面标题 22px/600、KPI 数字 32px/600、正文 14px、图表坐标 12px；页面和模块间距 24px；控件圆角 6px、卡片 8px；卡片只用细边框和轻冷灰阴影。

## 画面构图（桌面 1440×900）

生成一张中文高保真 B2B SaaS 后台截图，展示「华普智选」项目门面首页 P1 运营看板，路由 `/`。参考 Shopify Admin 仪表盘：熟悉、克制、信息可扫描，并保持 24px 呼吸感。

### 1. AppShell 与全局筛选

- 左侧 240px 深色侧栏 `#111827`，品牌「华普智选」；「运营看板」当前选中，`#312E81` 背景、白字、左侧 3px Indigo 指示条；其余六个导航项完整显示。
- 顶部 56px 白色顶栏，标题「运营看板」；中部平台切换「Amazon / 全部」，Amazon 仅为小 Tag；右侧角色「运营主管」、用户「张敏」。
- 主画布 `#F3F4F6`，24px 页面边距；内容顶部紧凑显示「数据概览」、时间范围「近 7 天」、更新时间「今天 16:42」，右侧 Secondary「导出报告」。

### 2. 顶部四张 KPI 数据卡

- 四列等宽白卡，卡间距 24px；每卡左侧必须有 4px 垂直 Indigo 主色条，圆角 8px、1px 细边。
- 卡片结构：12px 指标名 → 32px/600 大数字 → 环比/状态 caption → 右侧小线性图标或跳转箭头。
- 数据固定为：
  1. 「选品进度」主数字为待处理 `12`，辅助必须完整显示「待处理 12 · 已接受 28 · 已拒绝 7」，并有三个紧凑状态点或迷你条；
  2. 「未读告警」`3`，辅助「其中高风险 1」红色；
  3. 「监控竞品」`24`，辅助「近 24 小时 5 次变价」；
  4. 「库存风险」`2`，辅助「低于安全库存」琥珀色。
- 主色条统一 Indigo；语义色只用于小范围辅助数字，不把整卡染红/染绿。
- 四张 KPI 整卡可点击：选品进度 → `/recommendations?tab=pending`，未读告警 → `/inventory-alerts?tab=alerts&read=false`，竞品动态 → `/competitors`，库存风险 → `/inventory-alerts?tab=inventory&status=risk`；Hover 提升边框并显示右箭头。

### 3. 中部双图表

- 两张白色图表卡横向 1:1，间距 24px、高度一致。
- 左卡「品类增长率 Top 6」：水平或竖向柱状图，品类为开放式耳机、便携榨汁杯、宠物饮水机、旅行收纳、硅胶厨具、桌面加湿器；Indigo 柱为主，最高值可用绿色强调；显示 `18.6%` 等数据标签，灰细网格。
- 右卡「价格变动趋势 · 近 7 天」：两条克制折线「自营均价」Indigo 与「竞品均价」天蓝，美元纵轴、周一至周日横轴；最新点可见，面积填充不超过 8% 或不使用。
- 图表标题 16px/600，右上均有弱链接「查看详情」；禁止 3D、彩虹与粗重渐变。

### 4. 底部决策摘要三栏

- 底部采用约 30% / 36% / 34% 三栏，间距 24px，卡片高度协调。
- 左卡「最快增长品类」：紧凑榜单 1–4，显示品类、增长率与迷你条；第一名「开放式耳机 ▲18.6%」。
- 中卡「蓝海品类」作为唯一重点高亮卡：白底配 `primary-subtle #EEF2FF` 内层高亮或 2px Indigo 顶边，标题「开放式耳机」，绿色蓝海指数圆环 `86`，显示「需求高 · 竞争中 · 毛利 31.8%」，主链接「查看选品建议」。不能整卡渐变或发光。
- 右卡「AI 一句话摘要」：标题左侧仅一个克制的 `✨`，正文固定为「开放式耳机连续 4 周增长，竞品均价本周下降 3.2%，建议优先验证 $49–69 价格带。」下方显示「基于近 7 天数据 · 16:40 生成」与弱操作「重新生成」。

## 必须出现

- [ ] 路由 `/` 的项目门面首页，运营看板侧栏选中
- [ ] 顶部 4 张 KPI 卡，每张左侧 4px Indigo 色条和 32px 大数字
- [ ] 选品进度完整显示待处理 / 已接受 / 已拒绝，竞品卡显示近 24 小时变价条数
- [ ] 中部品类增长率柱图 + 价格变动双折线
- [ ] 底部最快增长榜、蓝海品类高亮卡、带 `✨` 的 AI 一句话摘要
- [ ] 全页模块间距 24px，浅灰画布、白卡片、低装饰高信息量
- [ ] 中文 UI，涨跌与风险语义色准确

## 禁止项

- 营销 Hero、欢迎口号占首屏、三张功能卖点卡
- 页面级紫粉渐变、蓝海卡整块渐变、玻璃拟态、霓虹或厚阴影
- KPI 卡使用四种大面积彩色背景；左侧主色条缺失
- 3D 图表、饼图堆砌、彩虹图例、装饰插画
- 超大圆角、胶囊按钮成排、闪烁 AI 徽章、Inter、英文 Lorem 或乱码

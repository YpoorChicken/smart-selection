## 画面构图（桌面 1440px 宽）

生成一张 **1440×900** 的高保真 B2B SaaS 后台桌面截图（中文 UI），展示「华普智选」完整 **AppShell + P1 运营看板内容占位**。

**布局（从左到右、从上到下）：**

1. **左侧 Sidebar · 宽 240px · 全高 · 背景 `#111827`**
   - 顶：品牌「华普智选」白字
   - 分组「看板」→ 导航项「运营看板」（**选中态**：背景 `#312E81`，白字）
   - 分组「选品分析」→「市场趋势」「选品推荐」（默认灰字 `#D1D5DB`；其中一项可示意 hover `#1F2937`）
   - 分组「运营执行」→「商品管理」「竞品监控」「Listing 优化」「库存预警」（库存预警右侧红色未读角标 `3`）
   - 底：弱化「退出登录」

2. **右侧主区**
   - **TopBar 高 56px · 白底 · 底部分割线 `#E5E7EB`**
     - 左：页面标题「运营看板」22px 半粗 `#111827`；其下或旁面包屑「看板 / 运营看板」12px `#6B7280`
     - 中左：平台筛选芯片「Amazon」「全部」（Amazon 小 Tag 橙系，不作大色块）
     - 右：角色 Tag「选品经理」+ 用户名「张敏」+ 圆形头像占位
   - **Canvas `#F3F4F6`，内边距 24px**，内容为运营看板占位：
     - 上排 **4 张 KPI 白卡片**（圆角 8px、细边框）：选品待处理 `12`、未读告警 `3`、竞品动态 `5`、库存风险 `2`；数字约 28px；可带小幅绿/琥珀环比 caption
     - 下方三栏信息模块（白卡片）：左「趋势摘要」简易折线（主色 `#4F46E5` 细线，无彩虹）；中「选品进度」待审/已接受/已拒绝小条或数字；右「竞品动态 / 库存预警」短列表 3–4 行（含涨跌绿/红数字）

整体气质：冷静、可扫描、高信息密度、像真实运营中台，不是营销落地页。

## 必须出现的 UI 元素清单

- [ ] 深色侧栏 240px + 品牌名「华普智选」
- [ ] 7 个导航项文案齐全（运营看板 / 市场趋势 / 选品推荐 / 商品管理 / 竞品监控 / Listing 优化 / 库存预警）
- [ ] 「运营看板」选中态（深 Indigo 底 `#312E81` + 白字）
- [ ] 至少一处导航 hover 或默认可区分的未选中灰字
- [ ] 「库存预警」红色未读角标
- [ ] 顶栏：标题「运营看板」+ 平台筛选 + 右侧用户/角色区
- [ ] 灰画布 + 白 KPI 卡与内容模块
- [ ] 看板占位数据（KPI 数字 + 趋势/进度/列表其一清晰可读）
- [ ] 中文界面文案

## 禁止项

- AI 紫粉 / 紫到靛蓝大面积渐变背景或侧栏渐变
- 玻璃拟态、霓虹光晕、多层彩色阴影
- Inter / Roboto webfont / 展示衬线 / 手写体作为主字体
- 三列营销 Hero、插画英雄图、表情包、贴纸徽章（NEW/HOT/AI 闪烁）
- 大圆胶囊按钮成排；圆角过大的「消费级 App」皮肤
- 深色内容区 + 浅色侧栏反转
- 把 Amazon 橙当整页主色或主 CTA
- 英文占位乱码、假浏览器框装饰喧宾夺主
